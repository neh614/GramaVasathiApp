# GramaVasathiApp

## Overview

GramaVasathiApp is an Android application developed to help citizens report village issues and access government-related services easily.

## Features

* User Login and Registration
* Report Local Issues
* Upload Images
* Track Complaint Status
* Notifications and Updates
* Firebase Integration

## Technologies Used

* Kotlin
* Android Studio
* Firebase
* Jetpack Compose

## Purpose

The main goal of this project is to improve communication between citizens and local authorities through a simple mobile application.
